# RIPE 对照的原生核心阶段

2026-11-06 新增 `internal/ripecore`，使用实际 PBC **非对称 Type F** 运算。
这是已固定 RIPE-BALANCED 公开策略算法的实现阶段；没有接入 `sanity` / `paper`
的性能案例或生成 RIPE 性能曲线。完整注册证明尚未实现，不能将本包当作
已完成的认证隐藏注册对照，也不能以核心时间替代端到端时间。

CHARE 正式实验仍使用原有 Type A 配置和原有协议。两个实现的群类型、密钥
输出及假设不同，不因在同一台机器运行就具备相同安全强度。

## 已实现的运算

- 一次源设置，保留零号槽、相关虚拟内积及全部异索引投影。公开退化检查
  失败就返回，不重取 CRS。内存中的设置标量不作为目录字段返回；Go 回收
  不保证物理擦除。
- 用户自主秘密和有上限的规范分母过滤；保留失败尝试的公共对象。
- 原始公钥与增量的实际配对一致性检查；包含未选中坐标。
- 只用公共记录和选择器生成与策略无关的加密系数及各用户帮助。
- 五个 G1 加一个 GT 的公开策略群消息密文、均匀 GT 密钥封装和局部解封装。
  不增加哈希密钥包装；它的输出不是 CHARE 的 32 字节密钥。
- 单资格的公开缓存替换，保留旧快照；增量验证后更新一个公共系数及其他
  接收者的对应帮助。字段复制也实际执行，不隐藏为零成本。

设置和固定样本分别保留以下取样域：alpha/beta/gamma、原始 r、s/z 非零；
t、u 和增量掩码为全域；虚拟向量均匀取非零向量。向量通过 `[1,p^d-1]`
整数的 p 进制展开产生，与该向量分布精确等价，并不把内积当作独立变量。
实现容量为 2..4096、属性数为 1..64。运行时熵源或原生库故障仍会返回错误。

所有点都有独立的 G1/G2/GT 类型和上下文，提供的运算不改变输入。当前只
接受可信的原生参数及生成的类型对象，没有实现任意不可信点的网络解码。
`NewTrustedContext` 的基本数值检查不是曲线安全认证或完整恶意参数验证。
公开参数须在创建后保持不变。

初始化还经过双方共用的 [原生群准入](NATIVE_GROUP_ADMISSION.md)，先排除
PBC 缓存单位元基点的实例，再执行本方案的一次源设置。这不重采样源 CRS；
失败与实际尝试次数独立记录。

## 特意保留的安全边界

`CheckKeyProjections` 不是注册知识证明。检查中有一个完全由公共点构造的
样例，能通过配对一致性，却没有给检查器提供规范私钥。原始 `IsValid`
安全缺口不能靠这个函数消失。真实注册者不应被要求额外公开秘密来替代证明。

尚未接入：根/发行行的 GS、DS、OTS 和完整抽取关系；资格凭证与发行日志；
实际标量配送；规范版本、代际和有效期；认证快照/帮助获取；完整序列化与
首次/重复获取；最强对照的同目标参数和批量实验。这些费用没有填零。

`Prepare` 与 `ReplaceIncrement` 是公共代数接口，不能越过上述认证/证明层。
本地快照指针检查用于防止开发时混用对象，不是线上认证、新鲜性或 CCA
保证。接收者资格检查和功能测试也不构成抗合谋安全证明。

缓存替换只验证新的公共增量，未实现机构授权判断。旧密文仍可用旧秘密和
旧帮助解开，符合不追溯收回旧明文的语义。新的发行行所需掩码必须经实际
配送后才能成为接收者本地材料；本包没有虚构免费的配送调用。

## 实际核验与一键入口

既有 `bash run.sh sanity` / `bash run.sh paper` 的完整 `go test ./...` 门槛
会包含本包，之后仍只运行原有 CHARE/source-DH 配置。单独核验可以运行：

```bash
go test ./internal/ripecore -count=1 -v
```

`testdata/f.param` 是原始 PBC 0.5.14 的公开功能夹具，非安全参数建议。
本机实际读出群阶 **158 位**，未压缩 G1/G2/GT 分别为 **40/80/240 字节**。
这些数据只描述这个夹具的编码；不是 128 位安全声明、同强度比较或测量
网格的参数推荐。原有 Type-A 参数文件没有改动。

测试逐式比较完整源密文的公开后处理与五分量版本；覆盖四类资格、A/B/AND、
空合取、单资格失效及旧状态、全部坐标检查、零增量、设置失败、密钥过滤、
真实随机采样、缓存与全量重算。失败会阻止既有脚本继续批量测量。

`AlgebraPayloadBytes` 明确只统计五个 G1 和一个 GT 的实际编码。策略、上下文、
证明、签名、参数、下载均不在这个值内；禁止将它标为完整密文字节数。
`Stats` 记录实际执行的对应群操作/随机调用，不是完整 CPU 工作或安全查询上限。

本轮不改变算法、源分布、注册格式或密码学假设，不给这个实现阶段增加
