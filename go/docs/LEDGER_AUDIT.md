# 保留观察的系数审计

交付修订：`v0.6.0 + ledger-audit-v1`。加密、认证、撤销、缓存、传输和批量测量
仍使用原 v0.6.0 算法与格式。本次增加独立 `internal/ledger` 包及功能测试，
不向旧实验数据补入新的测量值。

这个模块实际执行论文中的有限域线性代数，返回可检查的系数证书；它们不是签名
或零知识证明。它不从群元素
抽取离散对数、不恢复恶意注册者秘密，也不验证整个 GBGM/ROM 安全证明。
输入必须由审计者给出，并满足论文的原始来源、取样和观察语言条件。

## 输入与输出

`ledger.New(Input)` 接收指定设置的素数群阶、不同非零节点、每个普通来源的
原始槽位、独立掩码数量、数值观察的 `NumericalW/NumericalR` 和完整群点的
多项式/掩码系数。多项式按低次到高次排列，固定为容量 N 个系数；负数必须先
转换为 `0..p-1` 的规范代表。每个来源对应一个独立列，历史副本不能随意变成
新列。构造器检查尺寸、规范范围及节点/槽位，并复制输入。

群阶必须来自可信的指定设置；该包不签发素性证书，不接受任意不可信网络输入
作为一个生产服务，也没有实现自动来源身份或秘密状态跟踪。

- `Capability()` 返回普通来源能力空间的一组基。
  只有不含独立掩码的数值关系按槽位分离；完整群点通过联合掩码消去贡献整行。
- `Facts(shift)` 接收事先固定的原始事实差在普通来源上的系数 `A_t*d`。
  成功时返回各极点和多项式项的掩码位移原像；失败时返回实际左核行及其非零
  右端，规范化为内积 1。失败后的部分原像不能作为完整兼容证书。
- `Message(F, eta, gamma)` 是已给定真实系数的理论诊断。`eta` 可能依赖隐藏
  资格，因此目录不能把它当作自己可以查询的公开接口。成功时返回行空间保护
  证书；否则给出满足残余/能力约束且 `gamma*x=1` 的形式恢复系数。
  这不是完整解密器：实际生成还需要原始群元素的可执行表示。
- `PublicCertificate(F, gamma)` 仅实现论文保守的 `D=empty` 配置，完全不接收
  `eta`。成功时返回 `U*z=0`、`F^T*z=gamma` 的向量。失败表示**没有找到这一
  保守证书**，不表示能解密、不合格或系统不安全。

`F`、`gamma` 仍须来自相应真实目标。程序会拒绝尺寸不符、非规范系数及零
插值系数；不会从一个任意系数表证明其属于某条认证历史。调用者不能根据
已经看到的秘密开口另选事实对，再把结果解释成原始隐私游戏。

## 如何检查

现有一键入口 `bash run.sh sanity` 或 `bash run.sh paper` 的全量测试门槛已经
自动包含本模块，无需额外安装依赖。只运行系数功能测试可使用：

```bash
go test ./internal/ledger -count=1 -v
```

真实群元素见证测试位于 `internal/core/ledger_test.go`，需要正常 PBC/GMP 环境：

```bash
go test ./internal/core -run TestLedgerFactFailureWitnessInActualPBC -count=1 -v
```

新测试包括四类资格中诚实合格核心仍受保护、受控槽位残余消失后的形式见证、
完整群点与数值关系的区别、混合掩码、短/空矩阵、规范标量、输入/输出别名、
高次多项式以及匹配/不匹配的旧掩码开口。PBC 测试实际计算
`C1+C2-F0=y*B0`，并使用模块返回的左核系数，包括零掩码边界。

## 成本与范围

所有消元使用实际 `big.Int` 模素数运算。保存变换矩阵的步骤会产生额外平方
存储；本实现不是稀疏或增量求解器。能力空间的普通行化简不保存无用变换矩阵。
理论成本按普通来源数、掩码数、观察数和容量分别计费；研究目录中的
`ledger_implementation_20261106/ALGORITHMS_PROOF_AND_COST.txt` 给出推导。

本次没有对该模块生成性能曲线，也没有将测试耗时当作协议性能。已有原生
v0.6.0 批量数据仍对应原来的源码哈希；新增模块未接入计时的加密流程。
这种有限域判定与证书输出是论文方法的实现，不自动构成新的密码学贡献。
