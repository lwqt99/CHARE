# CHARE reference evidence module

Run `python3 RUN_REFERENCE.py` with Python 3.10 or newer. No network or
third-party Python package is required. The runner executes the public
coefficient controller scenarios and replays the saved actual-coordinate
fixtures against their original context and expected hashes.

The controller supports canonical core dictionaries, a proved polynomial
envelope, same-fact mask bindings under the ordinary-mask grant for message
analysis, and pad-only linear openings. Its target adapter uses canonical
empty-policy descriptors. The actual coordinate fixtures use the core-only
specialization. Trusted fixture manifests supply declared generation bindings.

The existing Type-A arithmetic is copied unchanged and checked against its
dependency hashes. The public replay child receives no expected key, private
fixture scalar, controller, or fixture generator. The parent checks exact,
nonempty, unique fixture coverage. Missing-opening errors test the recipe's
input contract; they are not a secrecy experiment.

The result confirms that this reference module is portable and executable.
It does not remeasure the original Go/PBC lifecycle or constitute the entire
submission artifact. The original manuscript, Go measurements and their raw
data retain their own provenance and submission entries.

`ASSEMBLY.json` records input identities. `MANIFEST.sha256` lists the packaged
files. The runner writes `INTEGRATION_RESULT.json`; fixture generation is not
part of its default path, so it replays the supplied public coordinates exactly.
